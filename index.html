Meeting notes from disclosed transcripts

把已向與會者說明的 Zoom 或 Teams 轉錄，整理成議程、討論、決定和待辦。轉錄只存在這個瀏覽器。

Turn a Zoom or Teams transcript into agenda, discussion, decisions, and action items. The transcript stays in this browser.

只限已披露的轉錄 Disclosed transcripts only 只可匯入已向與會者說明正在錄音或轉錄的會議。秘密錄音不要放進來。本站不會連接 Zoom 或 Teams，也不會上傳音訊。可選的「語音輸入」使用瀏覽器語音辨識；部分瀏覽器會把語音送到其供應商處理。 Import a transcript only when participants were told that recording or transcription was on. Do not use this for a secret recording. This site does not connect to Zoom or Teams and does not upload audio. Optional voice input uses the browser’s speech recognition; some browsers send audio to their vendor.

公開網頁，私人瀏覽器 Public page, private browser 這是公開的 GitHub Pages，任何人都可以打開這個介面。會議內容只存在你這個瀏覽器，除非你自己下載或複製。換電腦、無痕視窗，或清除網站資料之後，就不會再看到。 This is a public GitHub Pages site, so anyone can open the interface. Meeting notes stay in your browser unless you download or copy them. They do not follow you to another computer, a private window, or a browser after you clear site data.

如果這段文字一直在，代表程式沒有載入。請開啟 JavaScript，並用 GitHub Pages 或本機 http 伺服器打開，不要直接雙擊檔案。If this message stays, the script did not load. Enable JavaScript and open the site over GitHub Pages or a local http server, not by double-clicking the file.
